# Contributing

Thanks for wanting to help!

## Ideas and bugs

Open an issue with what you expected, what happened, and your Obsidian version. A screenshot of the base helps a lot.

## Code

1. Fork the repo and run `npm install`
2. `npm run dev` rebuilds `main.js` on every change
3. Copy `main.js`, `manifest.json` and `styles.css` into `<your vault>/.obsidian/plugins/bases-tag-colors/` and reload Obsidian
4. Check Table, Cards and Kanban views plus the note Properties panel, in light and dark themes
5. `npm run build` must pass before you open a pull request

Keep changes small and focused. Releases are built by GitHub Actions when a version tag is pushed.
